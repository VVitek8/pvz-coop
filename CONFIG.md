# coop_config.json — что за что отвечает
Файл читается при запуске `pvz_coop.py`. Нужен у **обоих** игроков; ключи, начинающиеся с `_`, игнорируются.

| ключ | значения | что делает |
|---|---|---|
| `name` | текст (латиница) | твоё имя, его видит друг |
| `port` | 7777 | TCP-порт хоста |
| `notify` | true/false | окошко «Player connected» |
| `allow_different_levels` | **false** / true | false: если друг на другом уровне, обоих держит на старте (зомби и падающее солнце ждут), сверху пишется, куда зайти. true: можно играть разные уровни, ничего не общее |
| `wait_for_partner_finish` | true/false | разные уровни: кто прошёл первым, ждёт окошком «Waiting for …», пока друг пройдёт свой (кнопка «Stop waiting» выходит из ожидания) |
| `no_pause` | true/false | игра не замирает при паузе/меню (флаг паузы сбрасывается каждый тик). Esc/потеря фокуса отключаются отдельно скриптом **02** в CT |
| `seed_choice` | **host** / both / off | host: семена выбирает хост, у клиента выбор повторяется за ним и кнопка «Let's Rock» заблокирована; both: выбирают оба (то, что кликнул один, повторяется у другого); off: каждый сам |
| `lock_client_start` | true/false | при `host` блокировать клиенту кнопку старта, пока хост не нажал |
| `start_wait_max` | секунды | максимум ждать друга на старте уровня, потом играть дальше |
| `sync.plants` | true/false | посадка/лопата/съели — у обоих |
| `sync.sun` | true/false | общий кошелёк солнца (только на одном уровне) |
| `sync.death` | true/false | зомби дошли до дома у одного — проигрыш у обоих |
| `sync.victory` | true/false | уровень пройден у одного — пройден у обоих |
| `sync.level_start` | true/false | первая волна зомби не идёт, пока друг не начал играть |
| `sync.cursor` | true/false | видеть мышь друга и растение у него в руке |
| `overlay.enabled` / `send_hz` / `color` / `show_name` | | рисование чужой мыши поверх окна игры |
| `no_plant_sync_modes` | список GameMode | где растения не синхронизировать (боулинг игра определяет сама) |
| `strings` | {"KEY":"текст"} | свои тексты меню: ключи TITLE HOST JOIN OK KEEP STOP RESYNC DISCONNECT CONNECT NEXT AGAIN CANCEL STOPWAIT. Если значение целиком вида `[DIALOG_BUTTON_OK]`, оно передаётся игре как настоящий ключ LawnStrings |
| `lawnstrings_path` | путь | полный путь к `LawnStrings.txt`, если он не нашёлся сам |
| `debug` | true/false | печатать смену сцен/уровней в консоль |

Всё общее работает **только пока оба на одном уровне** (одинаковый режим и номер уровня).
Зомби и падающее солнце не синхронизируются вообще (у каждого свои) — отдельного ключа для них нет.

## Тексты кнопок и LawnStrings
Для каждой надписи (Host Game, Keep, ...) скрипт сначала смотрит в `properties/LawnStrings.txt` распакованной игры:
нашёлся нужный ключ (наши `COOP_HOST`, `COOP_KEEP`, ... или `DIALOG_BUTTON_OK` / `DIALOG_BUTTON_CANCEL` для OK/Cancel) — в игру уходит `[КЛЮЧ]`, и игра сама подставляет свой текст.
Ключа нет (или файла нет, или игра запакована) — берётся обычный текст из кода, как раньше.
Свои ключи: вставьте содержимое `LawnStrings_coop_additions.txt` в конец `LawnStrings.txt` игры (и правьте тексты там). При старте в консоли пишется, какие ключи найдены.
`strings` в этом конфиге сильнее всего остального.

## Новое в v5
| ключ | что делает |
|---|---|
| `reward_lock` (true) | награду за уровень (трофей/карточка, типы в `award_coin_types`) никто не может взять, пока оба на одном уровне не прошли его. Пока ждёшь — награда убрана за экран и сверху написано, чего ждём; потом возвращается на место. При включённом `reward_lock` принудительная победа (`sync.victory`) не используется: каждый забирает свою награду сам |
| `lawn_resync` (5.0 с) | хост раз в N секунд присылает свои растения, клиент выравнивается (досаживает недостающие, убирает лишние, свежепосаженные не трогает). 0 = выключено |
| `sync.slots` | слоты: у клиента те же растения в слотах, что у хоста; если игрок взял растение из слота, слот начинает перезаряжаться у обоих |
| `sync.time` | клиент играет с той же скоростью и тем же временем, что хост (значение `[app+454]`, как в вашем скрипте ускорения; при расхождении больше `time_tolerance` тиков клиент чуть замедляется/ускоряется). Когда уровень кончился, исходная скорость возвращается |
| `overlay.fit` | auto (по умолчанию: подстраивается под ваш курсор, работает в окне, с чёрными полосами и любым масштабом Windows) / letterbox / stretch |
| `overlay.debug_self` | зелёный крестик там, где по расчёту ваша мышь: если он не совпадает с курсором — пришлите скрин |

**Все ждут хоста:** задержка старта уровня (`sync.level_start`) и окно «ждём друга» (`wait_for_partner_finish`) работают только у клиента; хост никогда не ждёт. Исключение — `reward_lock`: награду не берёт никто, пока не прошли оба.
