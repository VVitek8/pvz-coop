# PvZ Co-op v5 — как запустить

## Один раз на каждом ПК
1. Python 3 с галочкой «Add Python to PATH». В консоли: `pip install pymem`.
2. Одна и та же версия игры (PlantsVsZombies_insert.exe 1.0.0.1051) и одинаковые файлы из архива в одной папке.
3. Связь: Radmin VPN или Hamachi (оба в одной сети, IP вида 26.x.x.x / 25.x.x.x) или одна домашняя сеть. Порт 7777 TCP должен быть разрешён в брандмауэре.
4. По желанию: добавьте `LawnStrings_coop_additions.txt` в `properties/LawnStrings.txt` игры (см. CONFIG.md).

## Каждый раз
1. Запустите игру (не обязательно сразу в уровне).
2. Cheat Engine → прикрепить к игре → открыть `PvZ_Coop.CT`.
3. Включить скрипты по порядку: **00 CORE → 01A**. Если по F6 нет меню — выключить 01A и включить **01B** (нужен только один из двух). **02 NO-PAUSE** — по желанию (отключает паузу по Esc и при потере фокуса).
4. В папке с файлами: `python pvz_coop.py`. Должна появиться строка `ready`.
   Две игры на одном ПК: кликните по нужному окну игры, когда скрипт попросит (или `--pid НОМЕР`).
5. **Хост:** зайти в уровень, F6 → Host Game → Keep. Сказать другу свой адрес из Radmin/Hamachi.
6. **Друг:** вписать адрес хоста в `coop_peers.txt` (строка без #: `26.12.34.56 Zero`), в уровне F6 → Join Game → Connect.
   Без файла: `python pvz_coop.py --join 26.12.34.56`.
7. Оба должны быть в одном и том же уровне (если в конфиге `allow_different_levels: false`).
   Хост выбирает семена (`seed_choice`), когда хост нажимает старт, у друга уровень начинается тоже.

## Клавиши в уровне
F6 — меню, F7 — выровнять поле и солнце по хосту, F8 — отключиться.

## Выключение
Ctrl+C в консоли, затем скрипты в CE в обратном порядке (02 → 01 → 00; 00 последним).

## Если что-то не так
Запуск с `--debug` печатает смены сцен и уровней. Пришлите строки консоли и скажите, на каком скрипте и в какой момент.
